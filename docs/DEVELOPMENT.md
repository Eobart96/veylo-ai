# Разработка и проверки

## Команды

```powershell
npm ci
npm test
npm run check:backdrop
npm run check:rust
npm run desktop:app
```

`check:rust` выполняет cargo check и локальные тесты библиотеки. Тесты с реальным переводом помечены ignored и обычным запуском не отправляют данные в сеть. `desktop:app` собирает отладочную Windows-программу без установщика. Собственный Rust-код и кодеки в dev-профиле оптимизированы, диагностические сообщения сохранены.

## Интерфейсные проверки

`node scripts/check-adaptive-layout.mjs` поднимает временный локальный сервер и запускает изолированный headless Chromium. Проверяются размеры переводчика, экранные режимы, отмена, запоздалые ответы, безопасный текст и настройки клавиш. Используются искусственные события и данные, без захвата рабочего стола.

Нужны Playwright и Chromium. Для доступной установки Playwright можно указать `ARI_PLAYWRIGHT_MODULE`; для Chromium — `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. Сценарий также умеет находить локальную среду Codex, если она установлена. Playwright не является зависимостью приложения.

`node scripts/bench-capture-preview.mjs` сравнивает PNG-пути на искусственных пикселях с проверкой их сохранности. Опции сравнения производительности требуют исходных локальных baseline-файлов в `.cache/`, не включённых в Git; обычные проверки интерфейса от них не зависят. Результаты синтетических замеров не равны задержке перевода в игре.

## Реальные запросы

Сценарии `live-*.mjs` используют вход ChatGPT через Codex CLI и расходуют лимиты сервиса. Изображения в `tests/fixtures` созданы искусственно; там нет снимков пользовательского рабочего стола. Эти тесты запускают отдельно и не используют для доказательства точности любого игрового шрифта.

## Значки и Git

`powershell -File scripts/generate-icons.ps1` создаёт нативные PNG/ICO знака V в Windows. Векторный знак интерфейса — `public/mark.svg`.

`node scripts/audit-git.mjs` проверяет Git-кандидат на локальные пути, крупные файлы и известные признаки секретов, не печатая найденные значения. Это дополнительная проверка, а не гарантия отсутствия любых конфиденциальных данных. Не добавляйте `.tools`, `.cache`, `target`, `dist`, `.env`, журналы и личные настройки.
