# Архитектура Veylo AI

Приложение использует Rust + Tauri2 и локальный интерфейс TypeScript/CSS. Браузерный предпросмотр показывает оформление; нативные функции работают в Windows-приложении.

## Окна

- `main`: настройки, горячие клавиши, история переводов и сведения о проекте.
- `overlay`: отдельный переводчик с сохранением положения, размера и закрепления.
- `backdrop`: полноэкранный локальный кадр, выделение и плашки перевода.

`src/main.ts` управляет интерфейсом, `src/bridge.ts` — вызовами Rust, `src/backdrop.ts` — результатами на экране. Стили backdrop изолированы от главного окна.

## Нативная часть

- `overlay.rs`, `preferences.rs`: режимы окон и настройки.
- `hotkeys.rs`: глобальные сочетания, запись, конфликты, атомарное сохранение. Снимок настроек содержит `ready` и `revision`; событие `hotkeys-changed` обновляет интерфейс после регистрации и сохранения. До готовности ошибки регистрации не показываются, старые снимки не заменяют новые.
- `screen_capture.rs`, `screen_image.rs`: получение кадра Windows, вырезки, отмена, размещение блоков.
- `translation.rs`: ограниченный запрос к Codex CLI, JSON-схема и проверка результата.
- `session.rs`, `status.rs`: общее состояние локальных окон.

Текст и изображения считаются недоверенными данными. Переводящему процессу отключены инструменты и произвольные действия. Приложение не передаёт ему API-ключи из окружения. Содержимое ответа вставляется как текст, а не HTML.

## Состояние

Rust хранит текущие результаты и идентификатор поколения захвата. После отмены старый ответ не должен открывать закрытое окно. Настройки `overlay.json` и `hotkeys.json` находятся в каталоге конфигурации Tauri; черновики — в локальном хранилище WebView. Внутренний identifier `local.ari.overlay` и ключ черновиков сохранены при переименовании ради совместимости. Имя продукта — Veylo AI, исполняемый файл — `veylo-ai.exe`.

Полный кадр остаётся в памяти для соответствия координат. Повторное расширение области использует тот же кадр. Кэш отрисовки очищается после выхода; переключение оригинала не создаёт новый запрос.

Управление ПК помощником пока отсутствует; текущие системные действия ограничены окнами, горячими клавишами, снимком экрана и буфером обмена по команде пользователя.

## История
history.rs хранит текстовую историю вне репозитория. Отдельный FIFO-worker получает завершённые переводы и команды главного окна: чтение, включение/отключение, удаление, очистка, экспорт. Очередь сохраняет порядок между завершением перевода и последующей очисткой; файловые операции не задерживают GUI. Запись JSON атомарная, до500записей/8МБ; на обычном выходе очередь дожидается сохранения. Повреждённый файл не перезаписывается автоматически. История обновляется только после успешного результата и проверки поколения экранного запроса. Экспорт — отдельный JSON в Downloads/Veylo AI, создаётся только по команде. Снимки не сохраняются. history-view.ts показывает последние записи, поиск, копирование и управление; текст вставляется через textContent. API истории принимает команды только из main.
