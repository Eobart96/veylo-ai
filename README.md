# Veylo AI

**AI-помощник на экране.** Приложение для Windows с переводом текста, всего экрана, выбранной области и фрагмента под мышью.

Сейчас работает переводчик с отдельным настраиваемым оверлеем. Личный ИИ-помощник и управление ПК — будущие направления, они ещё не реализованы.

## Возможности

- Перевод текста: автоматический исходный язык, результат на русском, словацком или английском; ручные направления между этими языками.
- Перевод снимков в русский: весь монитор, выделенная область, цельный фрагмент под курсором. Переведённые плашки появляются на местах исходного текста.
- Отдельное окно переводчика: перемещение, изменение размера, булавка поверх окон, сохранение положения и размера.
- Настраиваемые глобальные горячие клавиши, проверка конфликтов и сохранение назначений.
- Переключение «Оригинал / Перевод» без повторного запроса.
- Локальная история переводов: поиск, копирование, удаление, отключение записи и выгрузка JSON.

## Запуск из исходников

Нужны Windows, Node.js22.12 или новее, Rust1.90 или новее с MSVC, Microsoft C++ Build Tools с Windows SDK и WebView2 Runtime. Для перевода нужен установленный Codex CLI с входом через ChatGPT и доступом к интернету. Использование расходует лимиты соответствующей подписки; ключ API приложению не требуется.

```powershell
npm ci
npm run desktop:app
.\Start-Veylo.cmd
```

Сборка создаёт `src-tauri/target/debug/veylo-ai.exe`. Для разработки: `npm run desktop`. Установщик NSIS: `npm run desktop:build`; это отдельная сборка, не опубликованный готовый релиз. Приложение пока экспериментальное и не подписано цифровым сертификатом.

Сценарий `scripts/setup-windows.ps1` предназначен для локальной установки инструментов. Он может устанавливать системные компоненты и требовать права администратора; запуск не нужен, если инструменты уже установлены.

## Горячие клавиши

| Действие | Стандартное сочетание |
|---|---|
| Открыть / скрыть оверлей | Ctrl + Shift + Space |
| Весь экран | Alt + Q |
| Выделить область | Alt + E |
| Текст под мышью | Alt + W |

Если стандартная комбинация занята, при запуске пробуется запасная. Фактическая клавиша показана в **Настройки → Горячие клавиши**. Нажми на сочетание и задай своё; Esc отменяет запись, «Сброс» возвращает стандартное значение. Поддерживаются Ctrl/Alt/Shift с буквой, цифрой или пробелом и F1–F24. В режиме перевода Esc закрывает кадр; Ctrl+Enter отправляет введённый текст. Клавиши работают, пока приложение запущено, в том числе когда главное окно скрыто в трее.

## История и сбор переводов

В главном окне есть раздел **«История»**. После успешного перевода сохраняются оригинал, перевод, дата, режим (текст/экран/область/курсор), выбранное направление и длительность. При исходном «Авто» поле направления отражает запрос, а не утверждает определённый ИИ язык. Для снимков сохраняется полный текст блоков, без ограничения поля ввода4000символов. Сами изображения не входят в историю.

История начинает собираться с этой версии, до500записей или8МБ; старые записи удаляются при превышении предела. Можно искать по оригиналу и переводу, копировать любой текст, удалить запись или очистить историю. Переключатель «Сохранять историю» отключает новые записи, не удаляя предыдущие. Ошибочные и отменённые запросы не добавляются.

**«Экспорт JSON»** создаёт файл со всей текущей историей в **Загрузки / Veylo AI**. Это явная выгрузка по нажатию, без отправки на сервер. История хранится в каталоге конфигурации приложения в `translation-history.json`, отдельно от проекта. Выгрузка содержит обычный текст и может включать личные данные; не добавляйте её в публичный репозиторий. Стандартные имена файлов исключены из Git и проверяются аудитом.

Если файл повреждён, приложение оставляет его без изменений и приостанавливает запись до явной очистки. Ошибка записи не отменяет готовый перевод. Очистка истории не удаляет отдельно сохранённые текстовые черновики или уже созданные выгрузки.
## Данные и ограничения

Перевод выполняется через Codex CLI. Введённый текст или выбранное изображение отправляются внешнему ИИ-сервису. Для области отправляется вырезка, для полного экрана — монитор целиком. Под курсором сначала отправляется полоса на всю ширину монитора, затем она может расшириться до всего монитора, если найденный блок обрезан краем. Чувствительные данные не следует включать в переводимую область.

Кадр фиксируется до выхода из режима, чтобы плашки соответствовали исходным координатам. Постоянного наблюдения за экраном или мышью нет. Отправляемый PNG временно хранится для CLI и удаляется при закрытии файлового дескриптора Windows. Текстовые черновики и настройки сохраняются локально. Выход по Esc отменяет локальный запрос; отправленная серверу работа могла уже начаться.

Точность распознавания, перевода и координат зависит от ИИ. Скрытый за прокруткой текст недоступен. Экран переводится в русский независимо от выбранной пары текстового переводчика. Возможны ограничения полноэкранных игр; предпочтителен оконный режим без рамок. Подпись «AI-помощник» описывает направление проекта: самостоятельное управление ПК ещё не добавлено.
